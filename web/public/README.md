# Static assets (public/)

Files in this folder are served at the site root and copied as-is into the
build output.

## Logo

Letakkan logo perusahaan di sini dengan nama **`dvl-logo.png`**:

```
web/public/dvl-logo.png
```

Header aplikasi memuatnya dari `/dvl-logo.png`. Jika file belum ada, header
tetap tampil normal (logo disembunyikan otomatis).

Catatan: beri nama tanpa spasi (`dvl-logo.png`, bukan `DVL logo1.png`) agar URL
tidak bermasalah.
